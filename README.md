# Shell-Chain White Paper

This repository publishes the English Shell-Chain white paper PDF.

## Download

- [Shell-Chain White Paper](./shell-chain-white-paper.pdf)

## Document

- Title: Shell-Chain White Paper
- Author: Shell Team
- Format: PDF, A4
- Language: English

## Scope

The paper describes Shell-Chain's clean-slate post-quantum blockchain
architecture, including post-quantum authentication, PQVM, wPoA finality,
algorithm agility, STARK-based accountability, and known deployment
boundaries.

This repository is intended for the release artifact. Source LaTeX files
and build outputs are maintained separately in the Shell-Chain white paper
source repository.
